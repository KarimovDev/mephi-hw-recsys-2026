Прототип книжного рекомендательного сервиса

Домашнее задание по курсу "Рекомендательные системы", датасет goodbooks-10k

На одних и тех же данных построены и сравнены четыре подхода: популярные книги, контентная модель на TF-IDF, Item-based CF и SVD. Работа разбита на шесть ноутбуков по этапам задания.

  1. Знакомство с данными и EDA
    Распределение оценок, активность пользователей, популярность книг, теги. Проблемы данных: разреженность, холодный старт, смещение популярности.
  2. Базовые и контентные модели
    Разбиение на train/test, топ книг по среднему рейтингу, TF-IDF по названию и тегам, поиск похожих книг.
  3. Item-based CF
    Разреженная матрица пользователь-книга, косинусная близость книг, предсказание оценки по K соседям, вычислительная сложность.
  4. SVD
    Матричное разложение из библиотеки surprise, подбор параметров, RMSE на тесте, рекомендации для пользователя.
  5. Оценка и сравнение моделей
    Precision@K, Recall@K и nDCG@K на отложенной выборке, сводная таблица.
  6. Гибридизация и выводы
    Гибрид для холодного старта, проверка на новых книгах, итоги и идеи для улучшения.
